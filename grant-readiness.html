Capture the artist’s reusable core information, then complete the additional questions needed for the selected funding route. The form can save a draft in the browser and export a working copy for TM360 review.

Application support, not automatic submission

This form prepares a working Grant Readiness Pack. It does not log into, populate or submit any funder’s portal. Programme questions, eligibility, dates and character limits can change, so TM360 must check the current official guidance before preparing a final application. The artist must verify and approve all information.
